# Markdown 本地链接检查器

这是《DeepSeek Harness：即插即用的实战指南》的入门练习项目。
它检查一份 Markdown 文件中的本地文件链接，报告不存在的目标；不访问网络，不修改文件。

在本目录执行 `npm run check`，检查 `docs/start.md`。执行 `npm test` 运行测试。
项目没有第三方依赖，不需要先运行 `npm install`。

输出每个不存在目标的原链接，最后打印检查数量。发现缺失目标时退出码为 1；全都存在时为 0。
练习材料有意保留一处过期链接，文件夹里有改名后的文档，可以据此判断怎样修正。

程序只处理普通的 `[文字](路径)` 写法，忽略纯锚点、绝对 URL 和站点根路径；不验证远程网页、Markdown 引用式链接或标题锚点。
