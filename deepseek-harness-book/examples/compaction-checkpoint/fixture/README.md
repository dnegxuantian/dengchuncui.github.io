# Markdown 本地链接检查器（练习项目）

发布文档前检查 Markdown 中指向本地文件的链接。目前有一个简单实现，需要逐步补充功能。

运行：`node src/check-links.mjs docs/start.md`

测试：`npm test`。不需要下载依赖。

代码里只解析 `[文字](链接)` 这种普通行内链接，不支持引用式链接、嵌套括号或完整Markdown语法。练习围绕现有语法补行为，不要求开发完整解析器。

`findLinks` 返回找到的目标，`checkFile` 检查一个文档，命令行入口打印检查结果。路径应相对于被检查的文档解析，而不是相对于终端当前目录。

目录中的链接涵盖正常文件、缺失文件、锚点、外部HTTPS链接和带空格的路径。这些是构造的练习数据，不是外部站点抓取结果。
