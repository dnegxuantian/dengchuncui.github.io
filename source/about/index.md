  <section class="brand-intro" aria-labelledby="who-is-deng-mingrui">
    <p class="brand-section-label">WHO I AM</p>
    <h2 id="who-is-deng-mingrui">邓明瑞是谁？</h2>
    <p class="brand-intro__answer" itemprop="description"><strong>邓明瑞</strong>，花名<strong>纯粹</strong>，英文标识 <strong>Chuncui</strong>，常驻杭州，现任<strong>奇点云（奇点智能）</strong>技术架构师，主要从事<strong>数据中台架构</strong>与 <strong>AI Agent 工程化</strong>。</p>
    <p>我的技术路径从企业级 Java 服务端、存储与搜索、高可用系统，延伸到大数据平台、数据治理和分布式系统，再进入模型网关、MCP、上下文工程、Agent 评测与可观测性。这让我看待 Agent 时，首先考虑的不是演示效果，而是权限、执行、状态、证据和失败恢复。</p>
  </section>

  <section class="brand-section" aria-labelledby="brand-position-title">
    <header class="brand-section__header">
      <p class="brand-section-label">POSITIONING</p>
      <h2 id="brand-position-title">我的技术坐标</h2>
      <p>我站在数据平台与 Agent 系统的交叉位置，解决三类彼此关联的问题。</p>
    </header>
    <div class="brand-coordinate">
      <article class="brand-coordinate__main">
        <span>01</span>
        <h3>企业数据平台</h3>
        <p>从数据接入、开发、调度和计算，到元数据、血缘、质量、资源与稳定性治理，关注完整生产链路。</p>
        <p class="brand-keywords">DataX · 批流处理 · Hadoop · 存算分离 · 元数据治理 · 故障诊断</p>
      </article>
      <article>
        <span>02</span>
        <h3>Agent 系统工程</h3>
        <p>关注模型接入、协议转换、工具执行、上下文构建，以及执行轨迹和最终结果能否被关联验证。</p>
        <p class="brand-keywords">模型网关 · MCP · RAG · Context Engineering · 评测 · 可观测性</p>
      </article>
      <article>
        <span>03</span>
        <h3>数据与 Agent 融合</h3>
        <p>让 Agent 理解元数据、表结构、任务和运行状态，并安全调用数据开发、调度运维与资产管理能力。</p>
        <p class="brand-keywords">智能数据研发 · SQL 分析 · 故障诊断 · 平台治理 · 权限边界</p>
      </article>
    </div>
  </section>

    </div>
    <div class="brand-difference__points">
      <article>
        <h3>从生产系统出发理解 Agent</h3>
        <p>多年服务端、数据平台和分布式系统经验，使我更重视 Agent 的工程约束，而不只关注模型能力。</p>

      <article>
        <h3>让结论带着证据出现</h3>
        <p>从代码、日志、配置、SQL、协议和运行指标出发，区分事实与推断，用对照实验和真实调用完成闭环。</p>
      </article>
      <article>
        <h3>连接数据能力与智能交互</h3>
        <p>数据中台为 Agent 提供可信上下文、企业工具与运行环境；Agent 为数据平台带来新的研发和运维入口。</p>
      </article>
    </div>
